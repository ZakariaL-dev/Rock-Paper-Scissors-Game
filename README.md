## 🌟 Overview
The **Rock Paper Scissors Game** is an engaging, web-based implementation of the timeless hand game. Built with **Vanilla JavaScript**, this project focuses on smooth state transitions, randomized AI logic, and a dynamic scoring system to provide a fun user experience.

## ✨ Key Features
* **🤖 Smart AI Opponent:** A randomized computer logic that keeps every round unpredictable.
* **📊 Live Scoreboard:** Tracks wins, losses, and draws in real-time during your session.
* **📱 Responsive Design:** Play seamlessly on any device, from mobile phones to wide monitors.
* **🎨 Animated Interface:** Features interactive buttons and visual feedback for every move.
* **🔄 Instant Reset:** Quickly clear the score and start a fresh session with one click.

## 🚀 Installation
Follow these steps to get a local copy up and running:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/ZakariaL-dev/Rock-Paper-Scissors-Game.git](https://github.com/ZakariaL-dev/Rock-Paper-Scissors-Game.git)
    ```
2.  **Navigate to the Project Directory**
    ```bash
    cd Rock-Paper-Scissors-Game
    ```
3.  **Launch the App**
    Simply open the `index.html` file in your preferred browser:
    ```bash
    open index.html
    ```

## 📖 How to Play
1.  Launch the application in your browser.
2.  Select your move by clicking on the **Rock**, **Paper**, or **Scissors** icon.
3.  The computer will simultaneously make its choice.
4.  The winner is declared instantly, and the scoreboard updates automatically!
